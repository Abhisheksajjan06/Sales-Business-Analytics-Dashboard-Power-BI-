# Sales-Business-Analytics-Dashboard-Power-BI-
This project transforms raw sales data into an interactive business intelligence dashboard using Power BI, Power Query, DAX, and data visualization techniques. The dashboard helps identify important business trends and provides actionable insights for decision-making.
🛠️ Technologies Used
Power BI
Power Query
DAX
Data Cleaning & Transformation
Data Modeling
Data Visualization
Excel/CSV
📌 Key Features
KPI cards for Total Sales, Total Profit, Orders, and Profit Margin
Monthly and yearly sales trend analysis
Sales by category and region
Top 10 product analysis
Customer performance analysis
State-wise and regional analysis
Interactive slicers and filters
Profit margin and sales growth calculations
Drill-through analysis
Conditional formatting
Interactive dashboard navigation
📈 Key Insights

The dashboard helps answer questions such as:

Which region generates the highest sales?
Which category is most profitable?
Which products perform best?
Which customers contribute the most revenue?
How are sales changing over time?
Which regions or products have lower profitability?
🎯 Objective

The main objective of this project is to demonstrate practical skills in Business Intelligence, data analysis, data visualization, Power Query, DAX, and Power BI dashboard development using a real-world business analytics scenario.
